Untuk aplikasi Matematika Kelas 1

Indonesia

Aplikasi Matematika Kelas 1 dikembangkan oleh FMI Studio. Aplikasi ini tidak mewajibkan akun, tidak memiliki sistem login, tidak meminta alamat email, dan tidak mengakses lokasi presisi berbasis GPS.

Aplikasi ini menggunakan Firebase Analytics untuk analisis penggunaan aplikasi dan Google AdMob / Google Mobile Ads untuk penayangan iklan. Layanan pihak ketiga tersebut dapat secara otomatis memproses data teknis perangkat, data penggunaan aplikasi, informasi koneksi dasar, data iklan, dan perkiraan lokasi umum berbasis IP atau jaringan sesuai kebijakan masing-masing layanan.

Tujuan penggunaan data

  • analisis penggunaan aplikasi
  • peningkatan kualitas dan performa aplikasi
  • evaluasi penggunaan fitur
  • penayangan dan pengelolaan iklan

Aplikasi ini ditujukan untuk pembelajaran anak dan tidak secara langsung mengumpulkan data pribadi seperti nama, email, atau lokasi presisi.

Karena aplikasi ini tidak memiliki akun pengguna dan tidak menyimpan data pribadi pengguna secara langsung dalam sistem milik pengembang, tidak ada akun pengguna yang dapat dihapus secara langsung oleh pengembang.

English

The Matematika Kelas 1 app is developed by FMI Studio. This app does not require an account, does not provide a login system, does not ask users to enter an email address, and does not access precise GPS-based location.

This app uses Firebase Analytics for app usage analytics and Google AdMob / Google Mobile Ads for advertising. These third-party services may automatically process certain technical device data, app usage data, basic network connection information, ad data, and general location estimates based on IP address or network connection, in accordance with their respective policies.

Purposes of data use

  • app usage analytics
  • improving app quality and performance
  • evaluating feature usage
  • displaying and managing ads

This app is intended for children's learning and does not directly collect personal data such as name, email address, or precise location.

Because this app does not provide user accounts and does not directly store personal user data in the developer's own system, there is no user account that can be directly deleted by the developer.
