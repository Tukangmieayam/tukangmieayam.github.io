Penghapusan Data

Aplikasi Matematika Kelas 1 tidak membuat akun pengguna, tidak memiliki sistem login, dan tidak menyimpan data pribadi apa pun di server mana pun.

Aplikasi hanya menggunakan Firebase Analytics untuk mengumpulkan data penggunaan yang bersifat anonim, seperti interaksi aplikasi dan informasi perangkat umum. Data ini tidak dapat digunakan untuk mengidentifikasi pengguna secara pribadi.

Jika Anda tetap ingin mengajukan permintaan terkait penghapusan data, Anda dapat menghubungi kami melalui email:

tukangmieayam@gmail.com

Karena aplikasi tidak menyimpan data pribadi atau akun, tidak ada data individu yang dapat dihapus. Namun kami akan membantu menjawab setiap pertanyaan atau permintaan terkait privasi.
